# Próximos passos

Estas são possibilidades de evolução, sem prazo ou compromisso de entrega. Recursos só devem aparecer como disponíveis no README depois de implementados e verificados.

## Entregue na versão 0.3

- Persistência de arquivos e programas em disco preparado.
- Ajuste automático de tela no VirtualBox.
- Desktop original com acabamento atualizado e assistente minimizado.

## Possíveis próximas etapas

- Facilitar a preparação da persistência com uma interface que identifique claramente o novo disco.
- Ampliar os testes para versões recentes do VirtualBox, BIOS e hardware físico.
- Avaliar um instalador de disco com escolhas claras e proteção dos dados existentes.
- Melhorar a seleção e configuração de um modelo local, com requisitos de memória visíveis.
- Avaliar integração opcional com o editor, mediante uma definição explícita dos dados acessados.
- Automatizar testes e publicar um processo verificável de releases e fontes correspondentes.

Voz, leitura automática de projetos, ações autônomas da IA e instalador de disco não fazem parte da versão 0.3.
